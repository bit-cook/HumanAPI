# Design notes

## Landing page direction

- Mode: existing codebase, expressive marketing surface.
- Retained the dark violet “digital-to-physical bridge” identity.
- Signature: a request/result signal connecting an AI Agent, HumanAPI, and a human expert.
- Type: Georgia for the physical-world thesis, Avenir Next/Segoe UI for body, SF Mono/Cascadia Code for protocol data.
- Removed mouse-tracking renders, client-side tab state, decorative emoji cards, and claims not implemented in the repository.
- Future passes should preserve evidence-based product copy and avoid introducing a second accent palette.
