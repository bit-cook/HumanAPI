Reference / MCP

MCP 工具参考

HumanAPI 通过单一的 POST /api/mcp 入口分派 12 个工具。请求使用 { tool, arguments } 包络，认证与限流与 REST 完全一致。

入口 POST /api/mcp 工具数量 12 参数风格 snake_case 认证 Bearer / x-api-key

01 / Envelope

调用方式

每次调用都是一个 POST 请求，body 为 { "tool": "<工具名>", "arguments": { ... } }。arguments 可省略（默认空对象），但 tool 必须是已声明的工具名，且请求体不接受额外字段。

请求示例

javascript · fetch
const response = await fetch("http://localhost:3000/api/mcp", {
  method: "POST",
  headers: {
    "content-type": "application/json",
    authorization: `Bearer ${process.env.HUMANAPI_API_KEY}`,
  },
  body: JSON.stringify({
    tool: "search_humans",
    arguments: {
      skills: ["现场调研"],
      location: { lat: 31.2304, lon: 121.4737 },
      max_distance: 5000,
      rating_min: 4,
    },
  }),
});

const result = await response.json();

读取工具清单

GET /api/mcp 返回工具名称列表、版本与本地基础 URL，同样需要认证：

json · 200
{
  "name": "HumanAPI MCP Server",
  "version": "2.0.0",
  "description": "MCP server for AI agents to book human experts for physical-world tasks",
  "tools": [
    "search_humans",
    "get_human",
    "book_human",
    "get_booking",
    "update_booking",
    "list_skills",
    "create_review",
    "send_message",
    "create_dispute",
    "get_dispute",
    "list_disputes",
    "resolve_dispute"
  ],
  "baseUrl": "http://localhost:3000/api/mcp"
}
命名差异：MCP 工具参数使用 snake_case（如 human_id、rating_min），REST 端点使用 camelCase（如 humanId、ratingMin）；两者操作同一份数据与同一套状态机。

发现与检索

TOOL search_humans

按技能、位置、费率与评分搜索可用专家，返回与 REST GET /api/humans 相同结构的档案列表。

参数

参数类型必填说明
skillsstring[]否技能标签，最多 50 个
locationobject否{ lat, lon }，用于距离匹配
max_distancenumber否最大距离（米），默认 10000
rate_minnumber否最低时薪
rate_maxnumber否最高时薪
rating_minnumber否最低评分（0–5）
available_nowboolean否仅当前可接单，默认 true

请求示例

javascript · fetch
const response = await fetch("/api/mcp", {
  method: "POST",
  headers: {
    "content-type": "application/json",
    authorization: `Bearer ${process.env.HUMANAPI_API_KEY}`,
  },
  body: JSON.stringify({
    tool: "search_humans",
    arguments: {
      skills: ["现场调研", "摄影"],
      location: { lat: 31.2304, lon: 121.4737 },
      max_distance: 8000,
      rate_max: 250,
      rating_min: 4,
      available_now: true,
    },
  }),
});

响应示例 · 200

{
  "success": true,
  "data": [
    {

      "name": "林晓",
      "avatar": null,
      "rating": 4.8,
      "totalReviews": 126,
      "skills": [{ "name": "现场调研", "verified": true }],
      "hourlyRate": 150,

预约与执行

TOOL book_human

一步创建任务与预约：任务直接置为 ASSIGNED，预约置为 PENDING。专家必须 verified 且 available，否则 409。

参数

参数类型必填说明
human_idstring是HumanProfile.id
task_descriptionstring是任务描述，≤ 10000 字符（前 100 字符作为标题）
task_locationobject是{ lat, lon, address?, city?, country? }
scheduled_timestring是计划执行时间（ISO 8601，含时区偏移）
estimated_durationnumber是预计时长（分钟），最大 10080
payment_amountnumber是报酬金额
agent_idstring是发起方 User.id（role 须为 AGENT）
payment_methodstring否支付方式标注

请求示例

javascript · fetch
const response = await fetch("/api/mcp", {
  method: "POST",
  headers: {
    "content-type": "application/json",
    authorization: `Bearer ${process.env.HUMANAPI_API_KEY}`,
  },
  body: JSON.stringify({
    tool: "book_human",
    arguments: {
      human_id: "hp_9k2f71xa",
      task_description: "拍摄三家门店的陈列照片并填写检查表。",
      task_location: { lat: 31.2304, lon: 121.4737, city: "上海" },
      scheduled_time: "2026-11-05T02:00:00.000Z",
      estimated_duration: 120,
      payment_amount: 300,
      agent_id: "usr_2b71de04",
      payment_method: "credit",
    },
  }),
});

const { booking_id, task_id } = (await response.json()).data;

响应示例 · 201

TOOL update_booking

更新预约状态。状态机与 REST 一致：PENDING → CONFIRMED → IN_PROGRESS → COMPLETED，CANCELLED 可从任意非终态进入。非法迁移或并发冲突返回 409。

参数

参数类型必填说明
idstring是Booking.id
statusenum是CONFIRMED / IN_PROGRESS / COMPLETED / CANCELLED
proofstring否完成凭据，写入 completionProof

请求示例

javascript · fetch
const response = await fetch("/api/mcp", {
  method: "POST",
  headers: {
    "content-type": "application/json",
    authorization: `Bearer ${process.env.HUMANAPI_API_KEY}`,
  },
  body: JSON.stringify({
    tool: "update_booking",
    arguments: {
      id: "bkg_5t8wa31q",
      status: "COMPLETED",
      proof: "https://files.example.com/reports/bkg_5t8wa31q.pdf",
    },
  }),
});

响应示例 · 200

json
{
  "success": true,
  "data": {
    "id": "bkg_5t8wa31q",
    "status": "COMPLETED",
    "updated_at": "2026-11-05T05:15:00.000Z"

参数类型必填说明
booking_idstring是Booking.id，须已 COMPLETED
reviewer_idstring是User.id，预约的 agent 或 human

03 / Errors

错误与状态码

MCP 路由复用 REST 的认证、限流与错误包络。包络校验失败（未知工具、多余字段、参数类型错误）返回 400，details 使用点分路径定位问题字段。

状态码error常见场景
400Invalid MCP request未知工具名、多余字段或参数校验失败
401Authentication required缺少或无效 API Key
404Human / Booking / Dispute not found引用的资源不存在
409Invalid agent / not verified and available / Cannot transition…状态冲突或资源不可用
429Rate limit exceeded超过每 Key 限额，带 Retry-After
500Internal server error未处理的内部异常

错误响应示例 · 400

json
{
  "success": false,
  "error": "Invalid MCP request",
  "details": [
    { "path": "arguments.rating_min", "message": "Number must be less than or equal to 5" }
  ]
}

04 / Client

客户端配置

仓库内置独立的 MCP stdio Server（mcp-server/）。构建后，在 MCP 客户端中添加如下配置，客户端会通过 stdio 调用本地进程，再由它请求 /api/mcp：

json · mcp client config
{
  "mcpServers": {
    "humanapi": {
      "command": "node",
      "args": ["/absolute/path/to/HumanAPI/mcp-server/dist/index.js"],
      "env": {
        "HUMANAPI_API_URL": "http://localhost:3000/api/mcp",
        "HUMANAPI_API_KEY": "与 API_KEY 相同的值"
      }
    }
  }
}
HUMANAPI_API_KEY 必须与服务端 API_KEY 一致；args 中的路径需为绝对路径。完整步骤见 快速开始 · MCP 客户端。
